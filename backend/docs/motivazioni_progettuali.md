# Motivazioni progettuali

## React
Scelto per realizzare una SPA modulare, riusabile e adatta a una UX moderna.

## FastAPI
Scelto per la rapidità di sviluppo, la tipizzazione e la documentazione automatica via OpenAPI.

## PostgreSQL
Scelto come database relazionale affidabile, adatto a dati strutturati e relazioni tra entità.

## SQLAlchemy
Scelto per l’ORM e per mantenere una separazione chiara tra dominio e persistenza.

## JWT
Scelto per gestire autenticazione stateless e proteggere le API.

## REST API
Scelte per semplicità, interoperabilità e naturale integrazione con il frontend React.
