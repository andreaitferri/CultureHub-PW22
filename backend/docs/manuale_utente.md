# Manuale Utente

## Accesso
1. Aprire il sito.
2. Selezionare Login oppure Registrazione.
3. Inserire le credenziali.

## Consultazione contenuti
1. Aprire Catalogo per vedere le opere.
2. Aprire Eventi per vedere le iniziative pubbliche.
3. Aprire il dettaglio di un elemento per maggiori informazioni.

Homepage, catalogo, categorie ed eventi pubblicati sono consultabili senza login.
Le opere archiviate e gli eventi non pubblicati non sono esposti agli utenti anonimi.

## Prenotazione
1. Aprire un evento.
2. Cliccare Prenota.
3. Indicare il numero di posti.
4. Confermare la prenotazione.

Il sistema controlla capienza e prenotazioni attive duplicate. Se l’evento è pieno
oppure l’utente possiede già una prenotazione attiva, la richiesta viene rifiutata.
Una prenotazione annullata libera nuovamente i posti.

## Feedback
1. Aprire il dettaglio evento.
2. Cliccare Lascia feedback.
3. Inserire voto e commento.
4. Inviare il feedback.

## Dashboard visitatore
La dashboard personale mostra prenotazioni e feedback dell’utente autenticato.
