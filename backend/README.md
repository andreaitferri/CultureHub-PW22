# CultureHub Backend

Backend della piattaforma **CultureHub** realizzato con:

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT
- Pydantic
- Swagger/OpenAPI

## Avvio locale

1. Creare il file `.env` partendo da `.env.example`
2. Installare le dipendenze
3. Avviare PostgreSQL e creare il database `culturehub`
4. Eseguire le migration o lo script SQL iniziale
5. Avviare il server FastAPI

## Endpoint principali

- `/api/v1/auth`
- `/api/v1/users`
- `/api/v1/categories`
- `/api/v1/catalog`
- `/api/v1/events`
- `/api/v1/bookings`
- `/api/v1/feedback`
- `/api/v1/dashboard`
